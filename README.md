# All Rent – homepage demo

Statische, responsive homepage voor All Rent Autoverhuur, gebouwd vanuit het Figma-ontwerp met de animaties uit Jitter.

- `index.html` – pagina (HTML, CSS en JS in één bestand)
- `assets/` – foto's, video's en Streamline-iconen

Lokaal bekijken: `python3 -m http.server` en open http://localhost:8000.
